# Digital Clock ⏰

A modern and visually appealing Digital Clock built using HTML, CSS, and JavaScript.

## 🚀 Features

- Displays current hours, minutes, and seconds.
- Shows the current date, month, and year.
- Displays the current day of the week.
- Shows AM/PM format.
- Attractive background image.
- Glassmorphism UI design using CSS backdrop-filter.
- Real-time clock updates using JavaScript.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
